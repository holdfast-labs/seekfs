The MP4 exports are 1920×1080, 30 fps, H.264/yuv420p with fast-start metadata.
The launch cut includes AAC audio; the README demos are silent. All essential
messaging is visible on screen. Use the MP4s when text readability matters;
the smaller GIFs are preview loops.

These are **illustrated walkthroughs**, not recordings of native interactions.
The UI is drawn from the released prompt layout. Results were checked with the
v1.11.0 CLI against a small public fixture, with local root prefixes removed:

```text
cmd/indexer/main.go      14 bytes
cmd/seekfs/main.go       14 bytes
cmd/seekfs/query.go      14 bytes
docs/main-guide.md       14 bytes
docs/release-notes.md
design/seekfs-logo.svg
```

`main` returns three files. `ext:go dir:cmd main` returns the two Go entry points.
`count main` returns three. The JSON scene abbreviates the results array for
readability. Typing and result-reveal timing is editorial animation, not a
latency measurement. No private files or measured speed claims appear.

## Sources and rights

- Video scenes and animation: [fframes Rust project](fframes), pinned to 1.2.0.
- Framework: [fframes](https://github.com/dmtrKovalenko/fframes), following its
  [official video skill](https://github.com/dmtrKovalenko/fframes/blob/main/skills/fframes-video/SKILL.md).
- Logo: existing `cmd/seekfs/ui_frontend/assets/seekfs-radar.svg`, extracted and
  resized for web use. The launch radar is a separate animated vector treatment.
- Music: original procedural composition, 120 BPM, generated by
  `fframes/scripts/soundtrack.py`; no sampled or third-party music.
- DM Sans and JetBrains Mono: bundled with their SIL Open Font Licenses under
  `fframes/licenses/`. Project-authored media uses the repository's MIT license.

The sources and marketing exports are outside `docs/`, so the application's
release packaging does not include the video-rendering dependencies or videos.

## Export checks

The three timelines passed fframes inspection with `--fail-on warning`: 122,
62 and 72 sampled/boundary frames respectively for launch, desktop and CLI.
Contact sheets and full-size frames were visually reviewed, including decoded
MP4 frames. All three MP4s decoded without errors and loaded in the browser
player at the expected dimensions and durations. Launch playback was verified.

FFprobe confirmed H.264/yuv420p at 1920×1080/30 fps, with 900/480/540 video
frames. The launch audio measured -14.0 LUFS integrated and -3.3 dB true peak
after encoding; fframes reported zero clipped samples. MP4 exports are remuxed
with fast-start metadata by `scripts/render.ps1`.
